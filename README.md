# Полезные ресурсы для собеседования в различных направлениях


Сборник материалов и вопросов с реальных собеседований для выхода на хорошо оплачиваемую работу; в ответ просим присылать свои вопросы в виде PR или записи интервью.
Начните с [ликбеза](docs/FromZeroToHero%20in%20QA%20%28AQA%29%20Interviews.pdf) по подготовке к собеседованиям (резюме, HR, торг по ЗП, первые офферы) — там есть ответы на 99% вопросов; если не нашли, спросите в [чате](https://t.me/+Ki_pB8xg72k4MzMy).
Есть также [список сайтов с вакансиями](docs/vacancy_source_list.md) (включая зарубежные), чтобы не ограничиваться HH.
