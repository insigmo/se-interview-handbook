## HR шпаргалка

# 🐍 Python — базовые вопросы

<details>
    <summary>Изменяемые и неизменяемые типы</summary>
    <p>
        Изменяемые можно менять без создания нового объекта (list, dict).  
        Неизменяемые — при изменении создаётся новый объект (int, str, tuple).  
        Важно для понимания побочных эффектов.
    </p>
</details>

<details>
    <summary>Декораторы</summary>
    <p>
        Функции, которые расширяют поведение других функций без изменения их кода.  
        Используются для логирования, ретраев и вспомогательной логики в тестах.
    </p>
</details>

<details>
    <summary>Итераторы и генераторы</summary>
    <p>
        Итератор — объект, по которому можно проходиться поэлементно.  
        Генератор — упрощённый итератор с yield, экономит память.
    </p>
</details>

<details>
    <summary>@abstractmethod и @property</summary>
    <p>
        abstractmethod — задаёт обязательный интерфейс.  
        property — позволяет обращаться к методу как к атрибуту, сохраняя инкапсуляцию.
    </p>
</details>

<details>
    <summary>ООП: инкапсуляция, наследование, полиморфизм</summary>
    <p>
        Инкапсуляция — сокрытие реализации.<br>
        Наследование — переиспользование кода.<br>
        Полиморфизм — один интерфейс, разное поведение.
    </p>
</details>

<details>
    <summary>copy vs deepcopy — в чём разница?</summary>
    <p>
      copy создаёт поверхностную копию объекта — вложенные объекты остаются общими.
      deepcopy рекурсивно копирует все вложенные объекты.
      Использую deepcopy, когда важно избежать побочных эффектов.
    </p>
  </details>
  
  <details>
    <summary>Как бы ты читал файл размером несколько гигабайт?</summary>
    <p>
      Читал бы файл по частям, используя итерацию по строкам
      или чтение чанками, чтобы не загружать весь файл в память.
    </p>
  </details>
  
  <details>
    <summary>Чем отличается list comprehension от генератора?</summary>
    <p>
      list comprehension сразу создаёт список в памяти.
      Генератор вычисляет значения по мере необходимости,
      что экономит память при работе с большими объёмами данных.
    </p>
  </details>
  
  <details>
    <summary>Что такое контекстный менеджер?</summary>
    <p>
      Контекстный менеджер управляет ресурсами,
      например, автоматически закрывает файл
      или соединение после выхода из блока with.
    </p>
  </details>
  
  <details>
    <summary>Как работает обработка исключений?</summary>
    <p>
      Исключения позволяют обрабатывать ошибки
      без падения программы.
      Использую try/except/finally для безопасной работы с ресурсами.
    </p>
  </details>
  
  <details>
    <summary>Почему не стоит использовать mutable объекты по умолчанию?</summary>
    <p>
      Потому что они создаются один раз при объявлении функции
      и могут привести к неожиданным побочным эффектам между вызовами.
    </p>
  </details>
  
  <details>
    <summary>Когда имеет смысл использовать yield?</summary>
    <p>
      Когда нужно обрабатывать большие объёмы данных
      или строить ленивые вычисления,
      не занимая лишнюю память.
    </p>
  </details>
  
  <details>
    <summary>Что происходит при передаче аргументов в функцию?</summary>
    <p>
      В Python передаётся ссылка на объект.
      Для неизменяемых типов создаётся новый объект,
      для изменяемых — возможны побочные эффекты.
    </p>
  </details>
  
  <details>
    <summary>Как бы ты объяснил GIL на базовом уровне?</summary>
    <p>
      GIL ограничивает выполнение байткода Python
      одним потоком, что важно учитывать
      при CPU-нагруженных задачах.
    </p>
  </details>
